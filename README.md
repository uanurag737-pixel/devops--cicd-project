# DevOps CI/CD Project

## Overview

This project demonstrates an end-to-end DevOps workflow using Git, GitHub, Jenkins, Docker, Docker Hub, and Kubernetes.

## Tools & Technologies

- Git
- GitHub
- Linux
- Jenkins
- Docker
- Docker Hub
- Kubernetes
- Minikube

## Application

A simple web application used to demonstrate CI/CD automation and containerized deployment.

## DevOps Workflow

Git → GitHub → Jenkins → Docker → Docker Hub → Kubernetes
